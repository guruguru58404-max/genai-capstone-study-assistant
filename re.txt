# StudyBuddy AI (GenAI Capstone Project)

A Generative AI study assistant. Upload your notes, pick a study mode, and chat. The agent decides when to search your notes or use a tool.

Live demo: ADD-YOUR-STREAMLIT-LINK-HERE

## What it demonstrates
| Skill | Where in the app |
|---|---|
| LLM API | Anthropic Claude via the Messages API |
| Prompt engineering | 3 study modes, each with its own system prompt |
| RAG | Notes -> chunking -> embeddings -> ChromaDB -> retrieval |
| Tools | search_notes, calculator, get_time |
| Agent | Understand task, decide action, use tool, process result, respond (max 6 steps) |
| Memory | Conversation state kept between messages |

## Architecture
mermaid
flowchart LR
    U[Student] --> UI[Streamlit chat]
    N[Notes PDF/TXT] --> C[Chunking] --> E[Embeddings] --> V[(ChromaDB)]
    UI --> A[Agent loop + Claude API]
    A -->|decide action| T{Tools}
    T --> S[search_notes] --> V
    T --> K[calculator]
    T --> M[get_time]
    T -->|result| A
    A --> UI


## Run locally

pip install -r requirements.txt
streamlit run app.py

Paste your Anthropic API key in the sidebar. The key is never stored in the code.

## Safety and limits
- API key entered at runtime only
- Calculator accepts numbers and operators only
- Agent stops after 6 steps
